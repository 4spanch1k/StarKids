# Initial Implementation Roadmap

## Phase 1: foundation

- establish repository conventions and env strategy
- scaffold backend app, admin panel, and mobile app
- add health checks and baseline routes
- define route and module boundaries

## Phase 2: operational core

- admin auth
- lead inbox foundation
- branches CRUD
- birthday packages CRUD
- tariffs CRUD
- promotions CRUD

## Phase 3: mobile slice 1

- app shell
- onboarding
- branch selection
- home shell

## Phase 4: mobile slice 2

- branch details
- gallery
- pricing and rules
- contacts and map links

## Phase 5: mobile slice 3

- birthdays index
- birthday package details
- birthday request flow

## Phase 6: engagement

- push token registration
- notifications center
- promotions targeting
- profile hardening or guest transition

## Exit criteria for MVP

- parent can discover a branch and request a birthday
- managers can see and process leads
- marketing can publish promotions
- push registration works end-to-end
